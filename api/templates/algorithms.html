Model Performance Comparison

We evaluate our models using Mean Absolute Error (MAE), which represents the average dollar amount our predictions differ from the actual market prices. Lower bars indicate better performance.

1. Deep Neural Network (PyTorch)

Our flagship model is a Multi-Layer Perceptron (MLP) built using PyTorch. It excels at finding non-linear relationships in highly complex datasets, such as how specific colors impact the price of a specific car brand differently.

2. Random Forest Regressor

The Random Forest algorithm builds a "forest" of multiple decision trees. Each tree makes a prediction, and the forest outputs the average. This model is incredibly robust against overfitting and handles outlier prices exceptionally well.

Configuration: We utilize 100 independent decision trees in our scikit-learn ensemble to guarantee prediction stability.

3. Multiple Linear Regression

Linear Regression forms our baseline model. It attempts to draw a "line of best fit" through all the features to determine base depreciation rates. While less accurate than Deep Learning for complex interactions, it provides highly interpretable weights.
